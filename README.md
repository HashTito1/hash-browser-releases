# Hash Browser releases

Installers and automatic-update files for **Hash Browser** (Hash for short), an Arc-style, privacy-first browser for Windows.

Hash Browser used to be called **Lumen**. Installed copies of Lumen update to Hash Browser from here, and keep their tabs, spaces, history, passwords and logins. Releases up to 0.1.12 still carry the old name.

Download the latest `Hash-Browser-Setup-<version>.exe` from [Releases](../../releases/latest). Installed copies update themselves from here.

The installers aren't code-signed yet, so Windows SmartScreen may warn the first time: choose **More info → Run anyway**.

What Hash Browser sends and doesn't, in plain words: [PRIVACY.md](PRIVACY.md).
